Data Backup — how to move data to a server / GitHub

Everything is stored in this browser's localStorage. To centralise it:

  1. Export the data below → save the JSON file.
  2. Put it in a private GitHub repo (or Gist) → get its raw URL.
  3. Tell classmates to Import the file here after opening the site, or paste the raw GitHub URL in Subjects → GitHub Resources to pull study links.
  4. For a true live multi-user backend you'd need a small server (Node/Python) — this static site keeps everything in the browser for simplicity.
